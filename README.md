# 学习阶梯教练（learning-ladder）

一个中文学习辅导 Skill：围绕“我想用 n 小时学习某主题”，帮助你制定计划、选择资源，并通过练习和复述检查理解。

## 能做什么

- **搭学习阶梯**：优先学习最有价值的核心内容，安排 m 次学习，每次 n/m 小时，包含目标、练习和复盘问题。
- **精选 5 个资源**：说明适合谁、难度、使用方法、可跳过部分，并对应到学习计划。
- **逐题考核**：一次只问一个问题，由浅入深；回答后按 0–10 分反馈正确、错误和不完整之处，只补讲未掌握的部分。
- **生成一页速查表**：包括一句话定义、核心概念、真实情境例子、常见错误和使用前检查清单。
- **复述训练**：先用 12 岁孩子能理解的语言解释，再请你用自己的话复述，指出遗漏、混淆和空泛术语，指导重讲。

## 安装

将本仓库下载为名为 `learning-ladder` 的文件夹，保留下面的文件结构，并让 Codex 将它安装到当前环境的个人技能目录。已安装过的用户可以直接开始使用。

这是指令型 Skill，无需额外的 Python 或 Node.js 运行依赖；筛选资源时需要联网才能核实最新页面。

## 使用步骤

1. **创建计划**：在 Codex 中调用技能，填写主题和总时长；学习次数可选。

   ```text
   $learning-ladder 我想用 6 小时学习「SQL」，分成 4 次。
   ```

   可以补充已有基础和用途，例如“零基础，目标是查询销售数据”。上例每次 1.5 小时；未指定次数时，教练会建议次数。

2. **开始学习**：收到计划和资源后，发送“开始第 1 次学习”，按当前知识块完成练习。
3. **逐题复盘**：发送“这块学完了，请考考我”，每次回答一个问题，按反馈修正理解。
4. **练习复述**：发送“请带我复述刚学的内容”，阅读通俗解释后用自己的话讲一遍，再根据反馈重讲。
5. **整理速查表**：主题结束后会生成速查表；也可发送“请把刚学的主题整理成一页速查表”。

练习、考核和复盘都计入总时间。“最重要的 20%”是选择核心内容的原则，不是精确比例或效果保证。可以随时暂停、跳过或调整目标。跨对话继续时，请附上次的进度小结或速查表。
