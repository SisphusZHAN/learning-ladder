# 逐题考核与复述训练

仅在考核、反馈答案或复述训练时读取。沿用学习计划和用户当前进度，不重启需求收集。

## 单问题交互

- 每次只提出一个需要用户回答的考核问题或一个复述任务，随后结束回复，等待真实回答。
- 一个问题只检验一个主要目标；不要用分号、多个小问或“另外”包装成一串题目。反馈中的改进要点可以列举，但不要把它们写成额外追问。
- 计划表里的复盘问题只是预览；进入考核后也不能一次发出整张问题清单。
- 不预先展示当前题的标准答案，不自问自答，不模拟用户后续回答。用户明确索要答案时可以解释，但仍需后续独立作答才能验证掌握。
- 先处理用户临时提出的疑问或暂停请求，再继续；用户选择跳过时标注尚未验证，不强迫完成固定轮数。

## 考官：由浅入深

根据本块目标选择题目，通常依次从识别或一句话定义，过渡到解释关系或机制，再到典型应用，最后在适用时检验新情境迁移或边界。不是每个小块都必须经历全部层级。

出题前确定本题期望的关键要点，随后按本题目标评分，不以未问到的高阶内容扣分。不因措辞与参考答案不同而扣分；合理的替代解法也应认可。

每个回答使用 0–10 分，并给一句评分依据：

| 分数 | 依据 |
| --- | --- |
| 0 | 未回答，或没有与本题相关的正确内容。 |
| 1–3 | 有少量相关知识，但核心结论或理解错误。 |
| 4–6 | 部分关键点正确，仍有影响本题理解或应用的错误、缺口。 |
| 7–8 | 核心正确且基本可用，有局部不严谨或遗漏。 |
| 9–10 | 准确、足以回答本题，并能说明题目要求的理由或应用。 |

根据内容正确性、与本题有关的完整性，以及本题要求的解释或应用能力综合评分。分数只是本题的形成性反馈，不代表整个学科的客观能力；有无法判断的答案时先澄清，不强行判错。

反馈格式保持紧凑：

- **得分：X/10。** 给出依据。
- **对的地方：** 指出用户回答中的具体正确内容。
- **错的地方：** 指明错误及正确区分；没有则写“本题未发现”。
- **不完整的地方：** 指明缺少的必要条件、关系或理由；没有则写“本题已覆盖关键点”。
- **只补这一点：** 有缺口时用一个针对性解释、对比例子或简短演示修正；没有缺口则省略，不重复整课。
- **下一题：** 只提出一个问题。若当前块已经达标，可结束本轮并说明下一步，不必机械追加题目。

核心错误未解决时，用稍有变化的同级问题复测，避免只让用户重复刚展示的句子。核心已正确时再提高难度，局部措辞问题不必造成无限复测。不要把“看懂了”“嗯”当成已掌握。

完成依据是用户能独立达到本块学习目标，而不是答完固定题数。通常至少需要准确解释关键内容，并完成适用的典型练习；纯概念主题可用辨析或举例验证。未验证的迁移能力应保持未验证状态。

## 复述训练：用 12 岁孩子能理解的话讲清楚

初次进入时，先给出简短、准确的通俗解释：用常见词语说明是什么、起什么作用，配一个具体例子。可以用比喻，但说明会导致误解的比喻边界；简化语言时不扭曲事实，也不使用居高临下的儿童口吻。

随后只给一个任务，例如：“现在请用自己的话，向一个没学过这个主题的人讲清楚它。”等待用户复述，不要求逐字背诵。

若用户已经提交复述，直接评价，不重放整段示范。对每轮复述给出 0–10 分和“已经讲清楚 / 还需修改”的判断，并逐项反馈：

1. 讲对了什么：引用或概括具体表达。
2. 漏了什么：只指出理解这个主题必需的缺口。
3. 混淆了什么：如概念层级、原因与结果、条件与结论。
4. 哪些词听起来高级却没解释清楚：指出具体术语，以及它缺少的通俗含义或因果说明；不是一律禁止专业词。

没有问题的类别明确写“未发现”，不为了填满格式虚构缺点。使用与考核相同的评分尺度，按准确性、关键内容完整性和通俗清晰度判断，不因表达朴素而扣分。

只针对尚未掌握的地方补充解释，优先处理最影响理解的缺口。然后给一个重讲任务，允许保留正确部分，重点改写有问题的段落；必要时再要求完整复述。不要每轮替用户写一篇可以照抄的成稿。

“讲清楚”的标准：核心含义准确、必要关系完整、例子与概念相符，且没有用未解释的术语替代关键说明。满足后明确结束该主题的复述循环，并按主文件生成或更新速查表；不为追求固定分数继续盘问。

若连续卡住，换例子、缩小范围或回补一个先修概念，再给一个任务；用户疲劳或要求结束时，记录未掌握点并暂停。学习循环受用户选择和时间预算约束，不能为了达标擅自延长总时长；预算将尽时说明剩余缺口，让用户选择调整范围、暂停或追加时间。
